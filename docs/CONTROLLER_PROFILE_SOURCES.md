# Sources des profils de contrôleurs

Les profils ci-dessous sont déclaratifs. Le statut `community` signifie que le
plan MIDI est documenté par le fabricant mais n'a pas encore passé la validation
matérielle complète de Controller Studio.

| Profil | Mode requis | Source officielle |
| --- | --- | --- |
| Akai Professional LPD8 MK2 | Program 1 configuré avec pads Note 36–43 et potentiomètres CC 36–43, canal 1 | [Guide officiel inMusic / Akai pour le Program 1](https://support.inmusicstore.com/en/support/solutions/articles/69000867977-lpd8-mkii-how-to-use-16-pads-and-knobs-in-mpc-beats) |
| Behringer X-Touch Compact | Standard, Layer A, canal MIDI 1 | [Quick Start Guide, MIDI Map Layer A](https://mediadl.musictribe.com/media/PLM/data/docs/P0B3L/QSG_BE_0808-AAE_X-TOUCH%20COMPACT_WW.pdf) |
| Behringer X-Touch Mini | Standard, Preset A, canal MIDI 11 | [Quick Start Guide, MIDI Map Preset A](https://mediadl.musictribe.com/media/PLM/data/docs/P0B3M/QSG_BE_0808-AAF_X-TOUCH-MINI_WW.pdf) |
| Behringer X-Touch One | MIDI mode, canal MIDI 1 dans ce profil | [MIDI Mode Implementation](https://mediadl.musictribe.com/download/software/behringer/X-TOUCH/Document_BE_X-TOUCH-ONE-MIDI-Mode-Implementation.pdf) |
| Novation Launch Control XL 3 | Default Mode 16, canal MIDI 16 | [Official Default Mode 16 parameters](https://userguides.novationmusic.com/hc/en-gb/articles/26260540230162-Launch-Control-XL-3-appendix) |
| Faderfox PC4 | Factory Setup 1, canal MIDI 1 | [PC4 User Manual V02, Factory settings](https://www.faderfox.de/PDF/PC4%20Manual%20V02.pdf) |
| Faderfox UC4 | Factory Setup 1, groupes encodeurs et faders 1 | [UC4 User Manual V02, Factory settings](https://www.faderfox.de/PDF/UC4%20Manual%20V02.pdf) |
| Faderfox PC12 | Factory Setup 1, canal MIDI 1 | [PC12 User Manual V04, Factory settings](https://www.faderfox.de/PDF/PC12%20Manual%20V04.pdf) |
| DJ TechTools MIDI Fighter Twister | Factory Banks 1–4, encodeurs canal 1, push/couleurs canal 2 | [MIDI Fighter Twister User Guide 2026, Appendix 1](https://drive.google.com/file/d/0B-QvIds_FsH3Z0ZLT041VnZfOTA/view?usp=sharing) |
| Korg nanoKONTROL2 | Mode CC, canal global 1, potentiomètres CC 16–23 et faders CC 0–7 | [Téléchargements officiels : Parameter Guide et MIDI Implementation](https://www.korg.com/tmp/support/download/index.php/product/0/159/?country=us&page=product&prodid=159&prodtype=0) |

Le X-Touch Compact disponible physiquement est le premier candidat à passer de
`community` à `verified`. Cette promotion exige la capture des messages réels,
le test de tous les contrôles déclarés et la vérification des retours.
